# Specification: Área de Colaboradores

## ADDED Requirements

### Requirement: Google Login & Role-Based Access Control
The application SHALL provide a `/login` page with Google OAuth 2.0 / OIDC. First-time users SHALL receive the `pendente` role unless their email is listed in `ADMIN_EMAILS`. Only `colaborador` and `admin` roles SHALL access `/painel`.

#### Scenario: First-time non-admin user signs in
- **WHEN** a user not in `ADMIN_EMAILS` completes Google OAuth
- **THEN** their account is created with role `pendente` and they are redirected to `/aguardando-aprovacao`, denied access to `/painel`.

### Requirement: Private R2 Storage & Presigned URLs
Binary files SHALL be stored in a private Cloudflare R2 bucket. Uploads and downloads SHALL use short-lived Presigned URLs generated by the server after role and file-type validation, without streaming large payloads through the Worker.

#### Scenario: Admin uploads and collaborator downloads a file
- **WHEN** an `admin` requests an upload URL for a valid file type
- **THEN** the server returns a Presigned PUT URL and records metadata in D1; when a `colaborador` requests download, the server returns a short-lived Presigned GET URL and logs the action in `audit_logs`.
